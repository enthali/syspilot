### Goal

Syspilot's process artifacts, skills, and setup guidance reflect what Jarvis-VSE learned while moving from v1 to Syspilot 0.10, so that a project with its own ontology file and its own role and Contract conventions can adopt them without rework.

### Value

Jarvis-VSE is the field-test lab for the next Syspilot release. Feedback absorbed here is tested in a real project before release, so the release is field-tested rather than assumed.
