# Contracts

This registry contains all process checklists of this project. A Syspilot process is a checklist that enables Syspilot actors to collaboratively create verifiable artifacts with declared ownership.

**Core principles:**
- Artifact ownership is process-specific. Each process declares which artifacts it produces and who owns them.
- This process registry is the single source of artifact ownership: each process declares its artifacts and owners, and each instance's artifact table states them once.
- Every artifact in a process has a guardian. An artifact without a guardian does not belong in the process.

The processes below were seeded from Syspilot's generic examples. The project owns them and tailors the `{...}` values to its own branches, tag form, and publication target.
