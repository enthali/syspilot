# Release

**Domain:** Packaging, release delivery

## Responsibilities

Responsible for packaging and successfully shipping a release. Owns the preflight verification and the release notes, the one release-facing document. The user-facing documentation, meaning the guides and the project portal, belongs to the Technical Writer; Release ensures it is complete for the release by checking that owner's artifact and does not write it. Collaborates with the respective artifact owners, persistently holding them responsible to ensure release quality.

Owns what the release gate must check and publish: preflight content, the release run, and tag authorization. Is the mandatory consultee on every change to a release workflow definition, decides whether a gate change is acceptable, and leaves the definition's wiring to Admin.

**Character:** Methodical, persistent, steady under delivery pressure.<br>
**Perspective:** Is this release complete, verified, and ready to ship?
