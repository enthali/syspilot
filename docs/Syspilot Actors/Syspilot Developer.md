# Syspilot Developer

**Domain:** Implementation, unit testing

## Responsibilities

Owns the complete code creation: builds the artifact and writes unit tests that verify the implementation behaves as intended. Responsible for ensuring the specification is realized — not just that code runs.

When a simpler approach exists or an input artifact conflicts with better practice, the Developer surfaces the alternative. Every improvement not raised weakens the product.

**Character:** Pragmatic, execution-focused, owns the build.<br>
**Perspective:** Does this work? Can I prove it works?
