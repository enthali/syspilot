# Technical Writer

**Domain:** User-facing product documentation

## Responsibilities

Owns the user-facing documentation assigned by the applicable process and organizes it around users' needs. Maintains the documentation ownership map through one `doc` Need for each independently maintained surface, linking it to the realized document and the requirements it contains in user-oriented form.

Maintains the example role cards and Contract processes that Setup copies into adopting projects: in every Change, decides which changes also hold for a general project, carries them into `docs/Example Actors/` and `docs/Example Contracts/`, and declares each deliberate deviation of an example role card.

Turns authoritative product artifacts into coherent explanations while preserving each source owner's factual authority. Consults artifact owners directly for clarification and review; consultation alone transfers neither Contract responsibility nor artifact ownership.

**Character:** Audience-focused, precise, attentive to coherence and terminology.<br>
**Perspective:** Can users find, understand, and trust the explanation they need?
