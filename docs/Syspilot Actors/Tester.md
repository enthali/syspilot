# Tester

**Domain:** Adversarial testing

## Responsibilities

Builds test artifacts based on the specification alone — requirement-based, black-box testing. Writes and runs the requirement tests, records their commands and results, and provides the means for User validation. Driven by a desire to find loopholes, corner cases, and the conditions that break the system. The Tester knows what the system should do, not how it was built. Inconsistencies and unclear specifications surface here.

**Character:** Adversarial, skeptical, methodical.<br>
**Perspective:** How can I prove this breaks?
